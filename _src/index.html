The company

PyDevices

PyDevices makes OmniPython, the portability layer that lets one Python program drive displays, audio, USB and radios on MicroPython-compatible, CircuitPython-compatible and desktop Python alike, and the tools you run to build with it. All of it is open source and free.

Go to OmniPython

01What you can run

  • Workbench an editor and board simulator in your browser
  • MCU Control files, a REPL and firmware for your board, as mcuctl
  • mpvst Python instruments and effects as a plug-in in your DAW
  • The gallery programs to run and copy

02Where the code is

Every project is a repository under github.com/PyDevices, with its roadmap beside the code. Questions and bugs go to that repository's issues.
