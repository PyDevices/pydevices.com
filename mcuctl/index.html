Board tool

MCU Control

The board tool for MicroPython-compatible and CircuitPython-compatible boards. It moves files, runs code, opens the REPL, installs packages and flashes firmware, from a terminal, from VS Code or from a desktop app, over USB, Wi-Fi or Bluetooth.

Command
mcuctl
Comes as
MCU Control CLI, MCU Control for VS Code and MCU Control Desktop
Source
PyDevices/mcuctl, MIT licensed

01The three parts

They share one settings file and the same commands underneath, so pick the one that suits how you work.

MCU Control CLI

The mcuctl command, with a browser interface (python -m mcuctl) for files, the REPL and firmware. It needs Python 3.9 or newer.

pip install -i https://test.pypi.org/simple/ --extra-index-url https://pypi.org/simple/ mcuctl

Only pre-releases are out so far, which is why the line names TestPyPI. Install and the CLI reference cover the rest.

MCU Control for VS Code

The same tool inside VS Code, Cursor, VSCodium and Google Antigravity: a dual-pane file view, the REPL, packages and firmware download and flash. It isn't on the VS Code Marketplace or Open VSX. Download mcuctl-*.vsix from the releases, then run Extensions: Install from VSIX…. Install has the details.

MCU Control Desktop

The tool as an app of its own, for Windows and Linux, with its own Python inside, so there is nothing to pip install first. It can also open a simulated board in a second window. It is a preview: the installers are on the releases page (.exe for Windows, .deb and .AppImage for Linux), they aren't signed yet, and it doesn't update itself. See the Desktop README.

02Try it without a board

MCU Control can hold a desktop MicroPython interpreter open the same way it holds a board:

mcuctl hold start --spawn micropython
mcuctl hold ask -d micropython "print(sum(range(10)))" --text
mcuctl hold stop -d micropython

For a board, name its port instead: mcuctl ls -d /dev/ttyACM0 /, or COM3 on Windows.
