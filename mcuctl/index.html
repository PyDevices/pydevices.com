Board tool

MCU Control

The board tool for MicroPython-compatible and CircuitPython-compatible boards. It moves files, runs code, opens the REPL, installs packages and flashes firmware, from VS Code, from a browser tab or from a terminal, over USB, Wi-Fi or Bluetooth.

Command
mcuctl
Comes as
a CLI, an extension for VS Code and Cursor, and a browser interface
Source
PyDevices/mcuctl, MIT licensed

01Install

pip install -i https://test.pypi.org/simple/ --extra-index-url https://pypi.org/simple/ mcuctl

That installs the mcuctl command and the browser interface (python -m mcuctl). For VS Code, Cursor and other compatible editors, download mcuctl-*.vsix from the latest release and run Extensions: Install from VSIX….

02Try it without a board

MCU Control can hold a desktop MicroPython interpreter open the same way it holds a board:

mcuctl hold start --spawn micropython
mcuctl hold ask -d micropython "print(sum(range(10)))" --text
mcuctl hold stop -d micropython

For a board, name its port instead: mcuctl ls -d /dev/ttyACM0 /, or COM3 on Windows.
