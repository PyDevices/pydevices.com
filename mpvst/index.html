Plug-in

mpvst

A VST3 plug-in whose instruments and effects are MicroPython-compatible scripts. Pick one from your DAW's browser, or write your own in a few lines of Python and point the plug-in at the file.

Format
VST3, for Windows and Linux
Tested in
REAPER
Source
PyDevices/mpvst

01Install

Download the archive for your platform from the latest release. Each has a .sha256 beside it to check it against.

Windows   run MPVST-<version>-windows-x86_64-setup.exe
Linux     tar xzf MPVST-<version>-linux-x86_64.tar.gz, then run the install.sh inside it

Then rescan plug-ins in your DAW, and make it a real rescan, not a restart: hosts cache what they found last time.

02Try this first

Search your FX browser for TR-808, Minimoog or Tape Delay and drop it on a track. Every instrument and effect shows up under its own name and category, with a patch selector, a bypass switch and a slider per macro in its editor. The two MPVST Script Host entries run a script you point them at, and stay silent until you do.
