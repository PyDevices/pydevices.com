PyDevices Workbench

A MicroPython IDE that runs in your browser, with a built-in simulator for MicroPython-compatible devices and the OmniPython libraries, and USB, Bluetooth and WebREPL connections to real boards.

01Try it

Press the simulator button, then type these lines at the >>> prompt to draw on the simulated display:

from board_config import display_drv
import pygraphics as pg
from palettes import get_palette
pal = get_palette()
w, h = display_drv.width, display_drv.height
buf = bytearray(w * h * 2)
fb = pg.FrameBuffer(buf, w, h, pg.RGB565)
pg.fill(fb, pal.NAVY)
pg.circle(fb, w // 2, h // 2, 80, pal.CYAN)
display_drv.blit_rect(buf, 0, 0, w, h)

A cyan circle appears on the navy display.
